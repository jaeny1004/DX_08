# 보고서 본문 자동작성 엔진 수정

수정 파일:
- rag-backend/app/services/report_draft_service.py
- rag-backend/app/services/report_template_service.py

주요 변경:
- 위험도/예찰/감염압력/접근성 값을 서로 다른 GeoJSON 컬럼으로 매핑
- 추진배경·목적·활용목적 및 대응계획 자동 작성
- 중심 격자 주변 최근접 4개 후보격자 자동 산출
- 선택 시군구 지도와 중심/인접 격자 이미지 자동 삽입
- 현장 예찰·방제 양식의 확인 가능한 항목 자동 작성
- 실제 현장 수량·검경 결과 등 없는 정보는 조작하지 않고 입력 필요 상태로 유지

주의: 예측 보고서 별지 표는 원본 양식에서 이미지로 들어 있어 실제 현장 접수·항공계획 데이터 없이는 자동 기입하지 않습니다.
